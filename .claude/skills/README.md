# Harbourline Labs: Role Skills

Working name: Harbourline Labs (checked 19 Oct 2026, see "Name check" below). A set of Claude skills that turn one owner plus Claude into a lean, modern IT company. Each folder holds a `SKILL.md` for one role. Start with `it-company-orchestrator`.

## Roles (15) plus orchestrator

| Skill | Why a small IT company needs it |
|---|---|
| it-company-orchestrator | Scopes work, chooses roles, sequences hand-offs, enforces gates |
| product-manager | Decides what to build and why |
| business-analyst | Turns needs into testable requirements |
| solutions-architect | Chooses the technical shape and records decisions |
| ux-ui-designer | Makes it usable, accessible and consistent |
| fullstack-engineer | Builds web apps and APIs |
| ai-engineer | LLM features, RAG, agents, evals |
| data-engineer | Pipelines, models, analytics |
| qa-test-automation-engineer | Prevents regressions, signs off quality |
| devops-cloud-engineer | CI/CD, cloud, reliability, cost |
| security-engineer | Threat models, reviews, compliance evidence |
| delivery-manager | Keeps delivery predictable |
| technical-writer | Docs that travel with code |
| customer-success-manager | Onboarding, support, retention |
| business-development-manager | Pipeline, proposals, pricing |
| digital-marketing-specialist | Demand generation and web presence |

## Name check (Harbourline Labs, 19 Oct 2026)

- ABN Lookup: no "Harbourline Labs"; many unrelated "Harbourline ..." entities exist (for example Harbourline Pty Ltd, Harbourline Medtech, Harbourline Spark), so a similar-name objection is possible.
- IP Australia: "harbourline" word marks are in classes 35 and 36 (real estate and other unrelated goods); none in software classes. No results for "harbor lab".
- Domains: harbourlinelabs.com, .au and .com.au unregistered at time of check (the .com.au via auDA WHOIS). Not yet registered by us.
- GitHub: harbourlinelabs handle unused. LinkedIn: not checked (sign-in required).
- Overseas: Harbor Lab, a maritime software company, is a similar-sounding name outside Australia.
- Not done: ASIC company-name reservation, formal trade mark advice. Register the domains and name promptly if proceeding.

## Research basis

Skills were derived from SEEK Australia role pages and job ads, LinkedIn-sourced listings and posts, and 2026 hiring guides across product, analysis, architecture, design, engineering, AI, data, QA, DevOps, security, delivery, writing, customer success, sales and marketing. Role pages report SEEK's own aggregated "skills employers look for"; several other sources are vendor or recruiter blogs, so treat their statistics as indicative. Direct LinkedIn and Seek job pages are only partly retrievable, so skills were cross-checked across multiple sources. Items marked as general knowledge (for example Australian compliance specifics) should be verified for each client.

## Install

Copy each role folder into your Claude skills location (for Claude Code: `~/.claude/skills/` or a project's `.claude/skills/`), or upload folders as custom skills.
